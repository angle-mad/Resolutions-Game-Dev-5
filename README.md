# Resolution Game Dev Week 5 Project

## How to Play
Move player with arrow keys.
Jump  with Spacebar

## Description
You play as a cookie trying to climb up the cotton candy platforms. Try to avoid peppermint spikes they will kill you. To gain a jump you must spell the word that shows up. You only gain a jump if you spell that word correctly. Using those jumps you have to scale up the cotton candy. There is a jump counter above your head to track how many jumps you can do.
